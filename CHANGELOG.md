# История изменений

## 0.1.0

Первый выпуск.

- Конструктор форм, список форм, заявки, настройки компонента.
- Всплывающие и обычные формы: класс, кнопка, шорткод, пункт меню; автопоказ по времени, прокрутке, уходу со страницы и бездействию.
- Защита от спама с оценкой по баллам: proof-of-work, ловушки, одноразовая метка, проверка присутствия человека, лимиты, чёрный и белый списки.
- Загрузка файлов с проверкой по началу файла, закрытым хранилищем и скачиванием только из админки.
- Уведомления: почта, Telegram, MAX; проверка каналов, журнал доставки, повтор при сбое.
- Срок хранения заявок с автоматической очисткой; данные о посетителе по переключателям; выгрузка в CSV.
- Интеграция с Dharma Shop: товар в форме и в заявке.
- Лёгкая загрузка: на страницах без форм только маленький загрузчик.
